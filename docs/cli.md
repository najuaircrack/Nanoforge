## Main command

```text
usage: latticekin [-h]
                  {params,registries,validate-config,new-config,auto-train,import,train-tokenizer,prepare,rag-index,inspect-dataset,validate-dataset,profile-dataset,clean-dataset,deduplicate-dataset,convert-dataset,tokenizer-status,tokenizer-report,benchmark-tokenizer,train,pipeline,pretrain,dpo,distill,tui,web,generate,chat,serve,export,benchmark,profile-config,evaluate,evaluate-suite}
                  ...

Local-first AI agent platform for CPU and GPU.

positional arguments:
  {params,registries,validate-config,new-config,auto-train,import,train-tokenizer,prepare,rag-index,inspect-dataset,validate-dataset,profile-dataset,clean-dataset,deduplicate-dataset,convert-dataset,tokenizer-status,tokenizer-report,benchmark-tokenizer,train,pipeline,pretrain,dpo,distill,tui,web,generate,chat,serve,export,benchmark,profile-config,evaluate,evaluate-suite}
    params              Estimate model parameter count.
    registries          List registered Latticekin component keys.
    validate-config     Load a config and validate registry-backed keys.
    new-config          Interactively create a CPU-friendly training config.
    auto-train          Train tokenizer, prepare data, write config, and train
                        in one command.
    import              Register an external GGUF, ONNX, SafeTensors, or
                        HuggingFace model.
    train-tokenizer     Train a BPE, WordPiece, or SentencePiece tokenizer.
    prepare             Pack raw text/code/JSONL into train.bin and val.bin.
    rag-index           Build a RAG vector index from documents.
    inspect-dataset     Inspect formats, fields, and warnings for input data.
    validate-dataset    Validate readable text records before tokenization or
                        packing.
    profile-dataset     Detect mode, text columns, and loss masking by
                        inspecting structure.
    clean-dataset       Clean, normalize, and deduplicate inputs into JSONL.
    deduplicate-dataset
                        Deduplicate inputs into cleaned JSONL.
    convert-dataset     Convert structured inputs to txt or JSONL text
                        records.
    tokenizer-status    Show native tokenizer acceleration status.
    tokenizer-report    Measure tokenizer compression and vocabulary usage.
    benchmark-tokenizer
                        Benchmark tokenizer throughput and memory use.
    train               Train from YAML config.
    pipeline            Run a multi-stage training recipe (e.g. pretrain ->
                        SFT -> DPO).
    pretrain            Pretrain a base model on raw text (mode=pretrain, no
                        loss masking).
    dpo                 Fine-tune with Direct Preference Optimization.
    distill             Train a student model with knowledge distillation from
                        a teacher.
    tui                 Launch the full-scope terminal UI.
    web                 Launch the full-scope web UI (React SPA + FastAPI).
    generate            Generate one completion.
    chat                Interactive chat.
    serve               Run the FastAPI inference server.
    export              Export model to GGUF (binary) or ONNX format.
    benchmark           Benchmark forward pass throughput.
    profile-config      Estimate params, FLOPs, and memory from config.
    evaluate            Evaluate checkpoint loss, perplexity, and token
                        accuracy.
    evaluate-suite      Evaluate a model against a JSONL task suite.

options:
  -h, --help            show this help message and exit
```

## Service and effect boundaries

Localhost is the default. Nonlocal binding requires the declared authentication/request policy;
TLS, tenants and an OS filesystem/network sandbox are separate deployment requirements.
Project providers select a model without granting tool capabilities.
Writes/tests require capabilities plus the applicable human approval policy.
Network model/data loading is explicit; checks use synthetic local data.
